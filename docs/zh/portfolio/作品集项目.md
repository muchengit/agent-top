作品集项目路径

强 Agent 作品集应展示四个梯度：RAG 和 memory、tool orchestration、multi-agent coordination、abstraction。

## Track 1：个人知识库 Agent

展示 RAG + memory。

最小范围：

- 本地 corpus。
- chunking 和 retrieval。
- 带 source references 的回答。
- user preference memory。
- missing evidence refusal。
- stale/irrelevant document evals。

## Track 2：企业多工具 Agent

展示 tool orchestration 和 MCP-style boundaries。

最小范围：

- tool allowlist。
- input/output validation。
- permission classification。
- destructive action confirmation。
- tool failure handling。
- observability logs。

## Track 3：多 Agent 协作系统

展示 orchestration、consistency、error isolation。

最小范围：

- router agent。
- retrieval agent。
- tool execution agent。
- verification agent。
- escalation path。
- shared trace model。
- error isolation and retry rules。

## Track 4：自定义框架或模式

展示 abstraction、engineering depth、contribution readiness。

最小范围：

- pattern spec。
- deterministic Lab。
- unit tests。
- tutorial with expected outputs。
- version anchors。
- failure mode documentation。

## 质量线

项目必须证明：

- 系统能运行。
- 系统能被测试。
- 系统能安全失败。
- 作者能解释 trade-off。
