# 作品集索引

作品集项目应证明你能构建、测试并解释 Agent 系统。

## 路径

- [`projects.md`](作品集项目.md)：完整作品集项目路径。
- [`personal-agent-portfolio.md`](agent项目作品集指南.md)：把 Agent 项目转成作品集材料。
- [`open-source-impact-guide.md`](开源贡献与外部影响力指南.md)：开源贡献与外部影响力。

## 四个项目梯度

1. **个人知识库 Agent** — 证明 RAG 和 memory。
2. **企业多工具 Agent** — 证明工具编排和 MCP-style 边界。
3. **多 Agent 协作系统** — 证明编排、一致性和错误隔离。
4. **自定义框架或模式** — 证明抽象、工程深度和贡献能力。

## 证据要求

每个项目应包含：

- 架构图或 Mermaid 流程。
- 可运行命令或测试输出。
- Eval 或 self-check 结果。
- 失败模式和回滚说明。
- Trade-off 解释。
- 相关 Lab 或文档链接。

## Reviewer 问题

- 项目能否本地运行？
- 是否区分证据和生成内容？
- 工具权限是否明确？
- 是否有失败路径，而不只是 happy path？
- 其他贡献者能否维护？
