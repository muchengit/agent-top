# L0 入门题

这一组题用于确认候选人在进入 Agent loop、工具调用或框架选择之前，是否已经掌握基础概念。

## 问题

### 1. prompt 和 system instruction 有什么区别？

听什么：

- prompt 是用户可见的请求或任务。
- system instruction 设定角色、约束、输出格式和安全边界。
- 候选人能给一个小例子。

好答案要点：

- system instruction 通常在多轮中保持稳定。
- prompt 可以随用户和任务变化。
- 能说出一个混用后的失败模式，例如安全边界变弱或约束泄露。

### 2. 为什么 context window 大小很重要？

听什么：

- context 是 instructions、history、tool results、output 的有限预算。
- 更大的 context 不会自动解决 latency、cost、噪声风险。
- 候选人能联系到 prompt trimming、summarization、retrieval。

好答案要点：

- 解释什么会被裁剪或摘要。
- 解释 overflow 在实践里长什么样。
- 提到关键证据应离当前任务更近。

### 3. 用大白话解释 tokenization。

听什么：

- 候选人知道文本会切成 token，而不是天然按词切。
- 知道 token 会影响 cost、latency、length limits。
- 知道字符数不等于 token 数。

好答案要点：

- 举一个 punctuation、code、多语言文本的例子。
- 把 token cost 和 prompt length、retry cost 连起来。
- 先做粗略预算，再谈精确 provider 计算。

### 4. 什么样的 Agent system prompt 才算好？

听什么：

- 有清楚的任务边界。
- 有输出格式或停止条件。
- 有工具使用策略。
- 有安全和升级规则。

好答案要点：

- 包含 refusal 或 escalation behavior。
- 包含 example 或 output contract。
- 避免隐式假设和过长指令。

### 5. 如何 debug 一个糟糕的 LLM response？

听什么：

- 候选人能区分 prompt、context、model、tool result、parsing 这些层。
- 会先看 logs、trace、sample input、expected output。
- 不会一上来就说“换模型”。

好答案要点：

- 从一个失败样本开始。
- 对比 expected vs actual。
- 先做最小可复现，再谈更大范围调优。

### 6. 什么时候 Agent 应该直接回答，而不是调用工具？

听什么：

- 候选人会先判断请求是否需要 live data、external action、authority。
- 能识别 ambiguity 和 risk。
- 知道什么时候直接回答也可以。

好答案要点：

- 稳定事实或澄清可以直接回答。
- 当前事实、权限、写入才走 tool call。
- 需要 certainty 或 safety review 时升级给人。

### 7. model output 和 final user response 有什么区别？

听什么：

- 候选人知道 raw model output 可能被 post-processing 改写。
- 能提到 validation、formatting、redaction、citation enrichment。
- 能区分 reasoning text 和 final answer。

好答案要点：

- final response 可能加 citations 或去掉 unsafe text。
- tool output 可能被 summarize 或 normalize。
- 调试时 trace 应同时保留 raw 和 final answer。

## 追问池

- 要一个“prompt 太模糊”的具体例子。
- 要一个“prompt 太死板”的具体例子。
- 问怎么在不损失质量的前提下降低 token cost。
- 问如果 prompt 稍微一改响应就变，他们第一步查什么。
- 问怎么向非技术同事解释 context limit。

## 常见红旗

- 把 context window 当成无限资源。
- 分不清 prompt、system instruction、tool result。
- 认为 token 数等于字符数。
- 没看 prompt 或 context 就直接建议换模型。
- 只会背定义，不会给 debug 路径。

## 作品集证据

L0 可接受的证据：

- 一个带 before/after 说明的 prompt rewrite。
- 一页 context limit 与 trade-off 说明。
- 一条展示 input、context、tool result、final response 的 tiny trace。
