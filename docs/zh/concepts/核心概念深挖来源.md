## 如何使用这页

1. 选择一个外部 source。
2. 先读对应的 Agent-Top 概念页。
3. 运行 linked Lab 或 case evidence。
4. 写下哪些是 stable pattern，哪些是 framework-specific。
5. 如果 source 暴露了 gap，开 `docs-only` 或 `lab` issue，并提交 scoped patch proposal。

## 贡献规则

- 不要整段复制外部教程。
- 提取 stable patterns 和 production trade-offs。
- Framework-specific API details 放在 Labs 或框架地图。
- 把 source 纳入 Agent-Top docs 时更新 `validated_date`。
- 优先使用本地可复现 evidence，而不是外部截图或断言。
