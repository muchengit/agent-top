# Agent 教程参考地图

这页把公开 Agent 教程和框架教程中的常见主题，映射到 Agent-Top 的稳定学习内容、Lab 和案例。

目标不是复制外部教程，而是把外部教程当作学习入口：映射概念、验证理解、产出可维护内容。

## 使用方法

当你阅读一个外部 Agent 教程时，按这 5 个问题拆解：

1. 它对应 Agent-Top 哪个能力层？
2. 核心内容属于稳定 pattern，还是框架 API？
3. 哪个本地 Lab 可以验证它？
4. 还应补充哪些失败模式？
5. 应产出什么文档、练习或 issue？

## 建议学习路径

1. 读一个入门 LLM Agent 教程。
2. 把它映射到 L0 或 L1。
3. 运行对应本地 Lab。
4. 写出一条外部教程和 Agent-Top pattern-first 视角的差异。
5. 如果差异有价值，提交 follow-up issue 或 docs PR。

```markdown
## Agent-Top Mapping
对应哪个能力层、Lab、案例？

## Gap or Follow-up

```

## 维护规则

不要把外部教程大段复制进 Agent-Top。只添加映射、摘要、trade-off 说明和原创练习。
