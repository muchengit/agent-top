# 开源模式矩阵

这个矩阵把 Agent-Top 的开源项目灵感提炼成可复用模式。补充教程、Lab、案例或生产指南时使用它。

## 如何使用

1. 选择要补的能力缺口。
2. 阅读模式定义。
3. 只把稳定原则加入 docs。
4. 框架特定细节保留在 Lab 或框架地图。
5. 链接到 evidence、eval 或 example。

## 模式矩阵

| Pattern | 解决的问题 | 稳定原则 | Agent-Top 落地位置 | 不要复制 |
| --- | --- | --- | --- | --- |
| Tool schema-first | 工具模糊和危险调用 | 先定义 input、output、risk、permission、audit，再写 prompt | [`../skills/工具MCP安全技能卡.md`](../skills/工具MCP安全技能卡.md)、[`../../../examples/agent-decision-trace/README.md`](../../../examples/agent-decision-trace/README.md) | Vendor-specific SDK boilerplate |
| Stateful graph workflow | 隐藏控制流和难调试循环 | 显式建模 state、transition、retry、checkpoint、stop | [`../concepts/Plan决策.md`](../concepts/Plan决策.md)、[`../../../labs/l3/multi_agent_supervisor/README.md`](../../../labs/l3/multi_agent_supervisor/README.md) | 整个 graph 框架 API |
| Role-based teams | 多 Agent 无界聊天 | 每个角色有职责、输入、输出和 stop condition | [`../concepts/多Agent调度.md`](../concepts/多Agent调度.md) | 示例 chat personas |
| Structured outputs | 自由文本输出破坏 pipeline | 模型输出经过 schema validation，再 retry 或 escalate | [`../concepts/Agent系统架构.md`](../concepts/Agent系统架构.md) | Provider-specific JSON mode examples |
| RAG evaluation | 检索看起来可用但回答不安全 | 分开评估 retrieval relevance、answer faithfulness、missing evidence、stale source | [`../production/评估与回归Playbook.md`](../production/评估与回归Playbook.md)、[`../../../examples/rag-evidence-refusal/README.md`](../../../examples/rag-evidence-refusal/README.md) | Tool-specific benchmark code |
| Memory lifecycle | 记忆陈旧或过隐私 | Extract、deduplicate、expire、delete，并按 owner 和 purpose scope | [`../concepts/长期记忆.md`](../concepts/长期记忆.md) | Memory provider data model |
| Observability contract | 事故无法 replay | 记录 request、prompt/model version、tool、retrieval、guardrail、memory、cost、latency | [`../concepts/核心Agent实施手册.md`](../concepts/核心Agent实施手册.md) | Dashboard 截图或 vendor setup |
| Prompt optimization loop | Prompt 调整靠猜 | Version prompts、定义 metric、在 eval set 上比较、只上线可测得提升 | [`../production/评估与回归Playbook.md`](../production/评估与回归Playbook.md) | 具体 optimizer internals |
| MCP policy proxy | 工具信任过度 | 把 auth、audit、mutation gate、redaction、rate limit 放在 execution 附近 | [`../concepts/MCP模型上下文协议.md`](../concepts/MCP模型上下文协议.md)、[`../skills/工具MCP安全技能卡.md`](../skills/工具MCP安全技能卡.md) | 完整 proxy 实现 |
| Runtime guardrails | 安全只存在于 final prompt | 在 side effect 前拦截 unsafe input、output、tool call | [`../production/安全清单.md`](../production/安全清单.md) | 黑盒 jailbreak datasets |
| 12-factor operations | 本地 demo 到生产失败 | 把 config、state、logs、scaling、release 当作架构问题 | [`../L4生产化.md`](../L4生产化.md) | 通用 devops boilerplate |
| Postmortem learning | 事故重复发生 | 把 incident 转成 eval、guardrail、trace field、rollback note 或 action item | [`../production/季度维护.md`](../production/季度维护.md)、[`../../../templates/postmortem-template.md`](../../../templates/postmortem-template.md) | 特定公司 incident template |
| Coding workspace boundary | Coding Agent 意外改仓库 | 把 repository context、command execution、file writes、tests、rollback state 分开 | [`../concepts/核心Agent实施手册.md`](../concepts/核心Agent实施手册.md)、[`../production/安全清单.md`](../production/安全清单.md) | 完整 editor plugin internals |
| Patch-first editing | 直接 mutation 难 review | 改代码前先产出可 review patch | [`../concepts/Agent设计审查清单.md`](../concepts/Agent设计审查清单.md)、[`../../../templates/contribution-checklist.md`](../../../templates/contribution-checklist.md) | Vendor diff UI |
| Test-driven Agent validation | Code Agent 改动未证明 | 每个 code-changing action 绑定最小 deterministic verification command | [`../production/评估与回归Playbook.md`](../production/评估与回归Playbook.md)、[`../../../labs/l4/regression_gate/README.md`](../../../labs/l4/regression_gate/README.md) | 完整 CI suite boilerplate |
| Source policy boundary | Agent 过度采集或过度检索 | 把 crawl、parse、store、retrieve、cite、ignore、block 作为独立决策 | [`../concepts/RAG记忆MCP数据流.md`](../concepts/RAG记忆MCP数据流.md)、[`../../../examples/data-source-policy/README.md`](../../../examples/data-source-policy/README.md) | Vendor crawler internals |
| Ingestion metadata contract | 检索证据无法解释 | 保留 source URL、crawl time、freshness、permission state、parser version、deletion state | [`../production/评估与回归Playbook.md`](../production/评估与回归Playbook.md)、[`../concepts/长期记忆.md`](../concepts/长期记忆.md) | 完整 vector store schema |
| Browser action trace | UI action 不可见且难 rollback | 记录 visible context、action intent、screenshot 或 DOM summary、rollback state | [`../concepts/核心Agent实施手册.md`](../concepts/核心Agent实施手册.md)、[`../production/安全清单.md`](../production/安全清单.md) | Provider-specific browser automation code |
| Structured output validation | schemaless output 破坏下游系统 | 加入 schema validation、retry budget、invalid-output escalation、failure logging | [`../concepts/Agent系统架构.md`](../concepts/Agent系统架构.md)、[`../production/评估与回归Playbook.md`](../production/评估与回归Playbook.md) | Provider-specific JSON mode code |
| Sandboxed execution boundary | Code Agent 可能运行危险命令 | 在执行前分开 shell、filesystem、network、credentials、approval gate | [`../concepts/核心Agent实施手册.md`](../concepts/核心Agent实施手册.md)、[`../production/安全清单.md`](../production/安全清单.md) | 完整 sandbox runtime |
| Eval gate discipline | prompt/tool/model 变更静默回归 | 要求 dataset version、pass rate、regression diff、owner approval、rollback plan | [`../production/评估与回归Playbook.md`](../production/评估与回归Playbook.md)、[`../../../examples/agent-eval-regression/README.md`](../../../examples/agent-eval-regression/README.md) | Vendor dashboard setup |

## 决策规则

- 如果模式改变 Agent 设计，加入 `docs/en/concepts` 并镜像中文。
- 如果模式需要可运行证明，新增或扩展 `labs` 下的 Lab。
- 如果用虚构数据练习安全决策，加入 `examples`。
- 如果模式涉及发布安全，加入 production guides。
- 如果模式是框架特定写法，放入 [`frameworks/框架地图.md`](../frameworks/框架地图.md)。
