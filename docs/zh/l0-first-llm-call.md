# L0 第一次 LLM 调用

## 目标

跑通第一次 LLM 请求/响应循环，并理解基础概念。

## 前置

- Python 3.10+
- 基础命令行使用能力

## 你应该学会

- Prompt 是用户指令。
- System prompt 定义助手角色。
- Response 是模型生成的文本。
- Token 不等同于英文单词。
- Context window 是模型可处理输入的预算。
