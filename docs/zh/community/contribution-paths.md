贡献路径

Agent-Top 有四类主要贡献路径。

## 1. 撰写

写新教程、概念页或 Lab。

好的写作贡献应包含：

- 清晰目标。
- 关联 Lab 或模板。
- 预期输出。
- Trade-off 解释。
- 通过 repository checks。

## 2. 翻译

翻译英文源内容到中文。

翻译贡献应：

- 使用相同 `i18n-key`。
- 更新 `last-synced`。
- 术语与 glossary 保持一致。
- review 后再关闭 `translation-needed`。

## 3. 审校

检查准确性、清晰度和可维护性。

## 4. 维护

维护框架地图、CI、模板和发布卫生。

## 常用标签

- `good first issue`
- `docs-only`
- `translation-needed`
- `sync-required`
- `lab`
