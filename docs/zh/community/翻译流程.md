翻译流程

英文 `docs/en` 是主源。中文 `docs/zh` 通过元数据保持同步。

## 必要元数据

```yaml
i18n-key: stable-key
last-synced: YYYY-MM-DD
```

## 流程

1. 英文源内容变化。
2. 添加或更新 `i18n-key`。
3. 打开或认领 `translation-needed`。
4. 翻译贡献者更新中文文件。
5. Reviewer 检查含义、术语和链接。
6. Maintainer 检查 `last-synced`。
7. 滞后则加 `sync-required`。

## SLA

- 主动认领后 3 个工作日内完成。
- 整体双语同步不超过 14 天。
- 不要静默保留过期中文内容。

## Review 清单

- `i18n-key` 与配对文件一致。
- `last-synced` 对应最新接受的源更新。
- 中文链接优先指向中文文件名。
- 框架名、品牌名、协议名除非 glossary 明确说明，否则不翻译。
- 技术术语与 glossary 保持一致。
- 示例中的 API、代码、命令不能因本地化改变含义。
- 翻译页没有 placeholder 或未翻译标题。
