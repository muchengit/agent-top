# 术语表

| 术语 | 中文 | 说明 |
| --- | --- | --- |
| Agent | Agent | 使用 LLM、工具、记忆、规划和控制循环完成任务的系统 |
| ReAct | ReAct | 推理与动作交替的循环 |
| Tool | 工具 | 外部函数或动作，有类型化输入输出 |
| MCP | MCP | 连接 LLM app 和 MCP server 的标准协议；server 可暴露 tools、resources、prompts、schemas 和外部 context |
| RAG | RAG | 基于检索增强的生成 |
| 记忆 | 记忆 | 跨轮或跨会话保留的上下文 |
| Guardrail | 护栏 | 防止不安全行为的规则 |
| Eval | 评估 | 衡量 Agent 行为的测试 |
| Trace | Trace | prompt、tool call、决策和结果记录 |
| Rollback | 回滚 | 恢复已知安全状态的路径 |
| Contract | 契约 | Agent 或工具的输入、输出、失败模式和验证约定 |
| Handoff | 交接 | 在 agent 或阶段之间传递任务状态、证据和下一步职责 |
| Verifier | 验证器 | 在最终回答前检查 evidence 和 recommendation 的组件或 agent |
| Human-in-the-loop | 人工介入 | 高风险步骤需要人工审批或复核的流程 |
| Fail closed | 失败关闭 | 停止或拒绝，而不是基于 unsafe assumptions 继续 |
| Regression Gate | 回归门禁 | 阻断 unsafe behavior 上线的发布门禁 |
| Blast Radius | 影响范围 | 失败影响的、数据或系统范围 |
| Postmortem | 复盘 | 把 incident 转成 prevention actions 的无责复盘 |
| Contributor | 贡献者 | 提交文档、翻译、Lab、问题或 review 的人 |
| Maintainer | 维护者 | 负责架构、安全、发布敏感变更审核的人 |
| Reviewer | 审阅者 | 负责普通文档、Lab 和术语一致性 review 的人 |
| Translation Needed | 待翻译 | EN source 稳定、ZH mirror 待更新的标签 |
| Sync Required | 需同步 | EN/ZH 内容 drift 或 last-synced 过期的标签 |
| Tested Against | 测试锚点 | 示例对应框架、SDK 或运行环境版本 |
| Validated Date | 验证日期 | 文档或示例被检查的日期 |
| Good First Issue | 新手任务 | 范围小、可测试、可独立 review 的入门 issue |
| Context Window | 上下文窗口 | 模型一次请求可处理的最大文本量，以 token 计 |
| Hallucination | 幻觉 | 看似合理但事实错误或无依据的模型输出 |
| Prompt | 提示词 | 输入给模型、用于指定任务或期望输出的文本 |
| Multi-Agent | 多 Agent | 多个 Agent 协作或协调完成任务的架构 |
| Supervisor | 监督者 | 负责协调和监督其他 Agent 的组件或 Agent |
| RAG Evaluation | 检索评估 | 衡量 RAG 系统检索与生成质量的评估过程 |
