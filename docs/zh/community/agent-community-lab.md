Agent Community Lab

Agent Community Lab 是轻量共学形式，把一个教程、Lab 或架构主题变成有产出的小组 session。

## 格式

- 60 到 90 分钟。
- 一个 host。
- 一个主题。
- 一个 runnable Lab 或 docs review。

## 产出

每个 session 至少产出一个：

- PR。
- Docs patch。
- Follow-up issue。
- Session notes。

## 角色

- Host：主持议程并记录结论。
- Contributor：提出一个小改动。
- Reviewer：检查准确性。
- Observer：记录阻塞和后续。

## Session 类型

- Tutorial walkthrough。
- Interview practice。
- Paper or article digest。
- Production retrospective。

## 规则

- 使用 `docs-only` 标记文档改动。
- 使用 `lab` 标记可运行 Lab。
- 使用 `translation-needed` 或 `sync-required` 标记双语缺口。
