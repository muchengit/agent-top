GitHub 标签

| 标签 | 含义 |
| --- | --- |
| `good first issue` | 适合新人的贡献 |
| `docs-only` | 仅文档改动 |
| `translation-needed` | 可认领翻译任务 |
| `sync-required` | 中英文不同步 |
| `deprecated` | 内容应指向替代页 |
| `breaking-change` | 框架或 SDK 变化可能影响示例 |
| `maintainer-review` | 架构或安全审查 |
| `lab` | 可运行 Lab 内容 |
| `interview` | 面试题或 rubric 内容 |
| `production` | 生产、安全、eval 或 postmortem 内容 |
