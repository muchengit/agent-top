Agent Community Lab

Agent Community Lab 是轻量共学形式，把一个教程、Lab 或架构主题变成有产出的小组 session。

## 格式

- 60 到 90 分钟。
- 一个 host。
- 一个主题。
- 一个 runnable Lab 或 docs review。

## 产出

每个 session 至少产出一个：

- PR。
- Docs patch。
- Follow-up issue。
- Session notes。

## 角色

- Host：主持议程并记录结论。
- Contributor：提出一个小改动。
- Reviewer：检查准确性。
- Observer：记录阻塞和后续。

## Session 类型

- Tutorial walkthrough。
- Interview practice。
- Paper or article digest。
- Production retrospective。

## 规则

- 使用 `docs-only` 标记文档改动。
- 使用 `lab` 标记可运行 Lab。
- 使用 `translation-needed` 或 `sync-required` 标记双语缺口。

## Recommended Cadence

建议节奏：双周发布教程，月度面试练习，双周论文或文章讨论，季度路线图或生产回顾。详见英文原文 [`agent-community-lab.md`](../../en/community/agent-community-lab.md) 的 Recommended Cadence 章节。

## Session Notes Output

结束时发布简短记录：主题、一页总结、可运行命令或相关 Lab、后续 issue 或 PR、是否需要更新文档。详见英文原文的 Session Notes Output 章节。

## Health Checks

好的 Agent Community Lab 应保持范围小、产出一个具体 artifact、保持 pattern-first、避免框架 churn，并给下一位贡献者留下清晰任务。详见英文原文的 Health Checks 章节。
