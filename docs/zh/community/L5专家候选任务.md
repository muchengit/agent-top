# L5 专家候选任务

这些是贡献者准备第一个 L5 evidence bundle 时可以选的任务包。它们刻意控制范围，方便 reviewer 只通过 pattern quality、governance evidence 和 influence artifacts 判断贡献，而不需要读私有系统。

## Pattern 贡献：证据门禁记忆写入

Problem：Agent 经常过早写入偏好，或把弱证据覆盖成强记忆。

Deliverables：

- Pattern contract，包含 inputs、outputs、safety checks、verification、rollback。
- 一个 deterministic Lab 或 example，展示 source preference、uncertainty threshold、write refusal。
- Eval report，覆盖 conflict cases、stale-preference cases、successful memory-write cases。
- Design review，列出 rejected alternatives：prompt-only memory、vector recall as truth、unrestricted memory writes。

Suggested labels：`good-first-L5`、`original-pattern`、`eval-evidence`、`safety-review`。

## Pattern 贡献：工具风险 Preflight

Problem：tool calls 可能跨越 read/write/destructive 边界，但没有明确 confirmation。

Deliverables：

- Risk classification contract，覆盖 read、write、destructive、external-state-changing tools。
- Preflight checklist 和 rollback hint template。
- Example trace，展示 block、approve-with-conditions、approved execution。
- Maintainer review notes，覆盖 destructive-action policy 和 audit fields。

Suggested labels：`good-first-L5`、`original-pattern`、`safety-review`、`eval-evidence`。

## Governance 贡献：Evals and Regression SIG Charter

Problem：如果没有 owner，eval quality 会分散在多个 PR 和个人习惯里。

Deliverables：

- Evaluations SIG 或 working group 的轻量 charter。
- Backlog 和 decision-log template。
- Monthly health update template，覆盖 eval coverage、blocker count、review latency、release instability。
- Contributor guide，说明学习者如何提交 reviewed eval evidence。

Suggested labels：`good-first-L5`、`release-governance`、`sig-candidate`、`external-impact`。

## Ambassador 贡献：Evidence Bundles Workshop

Problem：学习者知道 agent、eval、trace 这些词，但不能打包证明。

Deliverables：

- 30 分钟 workshop outline。
- 一个基于 L5 evidence template 的 worked example。
- Audience checklist 和 facilitator notes。
- 链接到 follow-up issue 或 contribution path。

Suggested labels：`good-first-L5`、`external-impact`、`original-pattern`。

## Reviewer 贡献：L5 Evidence Review Pack

Problem：maintainer 缺少统一 checklist 来 review 专家级 claim。

Deliverables：

- Reviewer guide，把 rubric dimensions 映射到 concrete evidence。
- approve、approve-with-conditions、rework、stop 的 comments 示例。
- 识别 overclaimed L5 readiness 的 checklist。
- Bilingual review notes。

Suggested labels：`good-first-L5`、`safety-review`、`release-governance`、`external-impact`。

## 如何使用这个页面

1. 选一个候选包。
2. 用相关 L5 labels 创建 issue 或 PR。
3. 链接 L5 expert evidence template。
4. 至少包含一个 failure path 和一个 rejected alternative。
5. 扩展前先请求 reviewer feedback。
