# 社区节奏

Agent-Top 用稳定节奏让贡献者知道预期，也让维护者能轮值而不 burnout。

## 常规活动

- 双周教程发布。
- 月度面试题更新。
- 季度路线图回顾。
- 双周论文或教程共读。
- 月度 showcase。
- 季度 hackathon。
- 双周 Agent Community Lab。

## 活动产物契约

每个活动应产出至少一个具体 artifact：

| 活动 | 必要产物 | 常用标签 |
| --- | --- | --- |
| 教程发布 | 新增或更新教程并验证 | `docs-only`、`lab`；架构变化加 `maintainer-review` |
| 面试题更新 | 题目、答案要点、rubric note | `interview` |
| 路线图回顾 | 状态更新和下一优先级 | `maintainer-review` |
| 共读 | 摘要、采纳模式或 follow-up issue | `good first issue` |
| Showcase | 项目链接、trade-off 摘要、lesson learned | `production`、`lab` |
| Hackathon | 可运行 repo、notes 或 reusable pattern candidate | `lab`、`maintainer-review` |

## 活动规范

- Agent Community Lab 是轻量小组活动：一个 host、一个 topic、一个 artifact。
- 每次活动前使用 host script 和 notes template。
- 议程保持小：15 分钟背景，30 分钟练习，15 分钟 review 和 follow-up。

## 运营规则

- 每个活动小到可以由志愿者负责。
- 每季度轮值 lead。
- 避免同一人同时承担作者和双审。
- 产出发布在主文档树，除非是可选附件。
- 社区 Lab 应产出 notes、PR、docs patch 或 follow-up issue。
- 如果活动发现 stale example，开 `sync-required`，不要悄悄绕过。
