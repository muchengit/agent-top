# 社区实验日志

本日志跟踪 Agent-Top 内容的实验提案。每季度一个实验：提出、原型、然后推广或归档。每条记录包含候选内容、决策与结果落点。

## 目标

- 让实验产出可审查。
- 每个实验都有明确的 promote 或 archive 决策。
- 在称模式可复用前，先与稳定基线做重复性对比。

## 条目格式

| 字段 | 含义 |
| --- | --- |
| ID | 唯一实验编号（`EX-001` 样式）。 |
| 状态 | `proposed`、`in-progress`、`promoted`、`archived`。 |
| 基线 | 实验前的既有行为或指标。 |
| 原型 | 原型所在的文件或 Lab。 |
| 决策 | 推广为内容或归档并说明原因。 |

## 重复性协议

社区实验验证一个模式时，记录其重复次数与证据。同一行为至少被两条独立 trace 或实现复现，且仓库中存在确定性测试，才认为模式可复用。

## 策略

- 每季度至少一个实验进入 `promoted` 或 `archived`。
- 只有原型通过仓库检查且存在确定性测试时才推广。
- 归档需写一行原因；不要静默删除原型。
