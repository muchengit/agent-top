# 月度贡献者

## 目标与价值

月度贡献者计划表彰在一个日历月内交付了有意义、可审查、可复现工作的贡献者。它存在是为了奖励稳定贡献而不是单次刷量，并通过突出那些降低维护负担的人，让社区的审查负载可持续。

好的奖项不是人气竞赛，而是有证据支撑的决策：合并的 PR、审查评论、翻译同步提交、CI 修复，以及其他贡献者可验证的"帮别人解卡"行为。

## 入选条件

当月满足以下任一条件的贡献者即可提名：

- 合并了教程、文章、Lab、面试题或案例研究。
- 合并了完整或部分翻译，并保持了 `i18n-key`、更新了 `last-synced`。
- 用实质性（而非只点批准）的反馈审查了 PR。
- 修复了 CI、模板、版本锚或贡献流程。
- 在 issue、Discussions 或社区实验中帮别人解卡。
- 通过示例、清单和审查反馈维持了高标准。

不活跃的月份不取消资格。一个人可以再次获奖，但之前的获奖不应成为决定性因素。

## 提名窗口与时间表

使用以下固定日程（时间均为 Asia/Shanghai）：

| 截止时间 | 动作 | 负责人 |
| --- | --- | --- |
| 当月 25 日 | 打开提名 issue | 轮值维护者 |
| 26-28 日 | 收集证据与评论 | 贡献者、审查者 |
| 29 日 | Core 团队确认获奖者 | Core 团队 |
| 30/31 日 | 发布报告与徽章 | 轮值维护者 |
| 次月第一周 | 在 showcase 与 release notes 宣布 | Core 团队 |

如果月末是周末或公共假期，把截止时间顺延到下一个工作日，并在提名 issue 里说明。

## 角色

- **提名人**：打开提名 issue 或添加证据的维护者/贡献者。
- **证据收集者**：轮值维护者，把每个候选声明链接到 PR 或评论。
- **确认者**：Core 团队，检查规则并确认获奖者。
- **宣布者**：轮值维护者，发布报告。

一个人可以兼任多个角色，但确认者不能是获奖者。

## 评选标准与打分

每个维度按 10 分制打分：

| 维度 | 什么算证据 | 权重 |
| --- | --- | --- |
| 文档质量 | 合并的文档、有效链接、更新 `validated_date` | 25% |
| Lab 可运行性 | 带代码、测试且本地检查通过的 Lab | 25% |
| 翻译或审查质量 | 同步提交、`last-synced` 更新、审查反馈 | 20% |
| 帮助新人 | 能解卡的回复、入门审查、指导 | 15% |
| 降低维护负担 | CI 修复、模板更新、过期内容标记 | 15% |

候选人平均分至少 7.5 才被考虑。如果无人达标，本月跳过该奖项；不要降低门槛。

## 评选流程

1. 轮值维护者在 25 日打开提名 issue，列出来自已合并 PR 的候选名单。
2. 每位候选人获得一条带链接证据的顶层评论。
3. 审查者与贡献者在 28 日前添加支持或反对评论。
4. Core 团队在 29 日审查打分表、应用公平规则并确认获奖者。
5. 轮值维护者填写 [`../../templates/monthly-contributor-report.md`](../../../templates/monthly-contributor-report.md) 并发布到社区索引。
6. 获奖者获得徽章和下文所述权益。

## 权益

- 下次社区 showcase 的徽章。
- 一个月内低风险 `docs-only` PR 的审查开销减免。
- 在 release notes 或路线图回顾中的优先曝光。
- 可主持一次社区实验（使用 [`../../templates/community-lab-template.md`](../../../templates/community-lab-template.md)）。

减免审查只适用于 `docs-only` PR，且不跳过 `maintainer-review` 路由。

## 公平规则

- 同一人不得在同一月既当同一 PR 的作者又当第二审查者。
- 提名必须链接证据；无支撑的声明会被丢弃。
- 贡献必须可审查、可回滚、可复现。
- 不允许只自荐；必须有第二人附议。
- 如果获奖者恰好是轮值维护者，由 Core 团队宣布。

## 常见问题与处理

- **证据质量低**：让收集者链接 PR 编号；仍然单薄就跳过奖项。
- **候选人并列**：先比审查与帮助新人分数，再比降低维护负担。
- **获奖者休假**：奖项保留；宣布等获奖者能回复时进行。
- **同一人重复获奖**：允许，但需要比上次更强的证据。
- **提名争议**：Core 团队在 3 天内于公开 issue 重查打分表。

## 可衡量指标

每月追踪并与上季度对比：

- 每月提名数量。
- 带至少一个链接 PR 的提名比例。
- 获奖者合并 PR 数与审查评论数。
- 从提名 issue 到发布报告的时间（目标少于 7 天）。
- 纯翻译贡献获奖者的占比（不应为零）。
- 跳过月份数（目标每年少于 2 次）。

## FAQ

- **维护者能获奖吗？** 可以，但不能在确认奖项的同一月。
- **单个大 PR 算吗？** 算，但更偏好稳定的多个小 PR。
- **能自荐吗？** 可以，但需要第二个贡献者附议。
- **本月没有获奖者怎么办？** 跳过并发布简短说明解释原因。
