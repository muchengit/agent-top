# 速查表索引

速查表是 Agent-Top 的快速查阅层。

## 速查表

- [`agent-glossary.md`](Agent术语表.md)：Agent 核心术语。
- [`architecture-patterns.md`](架构模式速查.md)：架构模式地图。
- [`lab-command-cheatsheet.md`](Lab命令速查.md)：本地命令和 Lab 导航。
- [`production-checklist.md`](生产清单.md)：生产发布检查清单。

## 适用场景

- 面试准备。
- 实现前审查 Agent 设计。
- 新贡献者快速查命令。
- 发布前检查 Lab 或生产改动是否就绪。

## 推荐阅读顺序

1. 先读 [`agent-glossary.md`](Agent术语表.md) 建立术语。
2. 用 [`architecture-patterns.md`](架构模式速查.md) 选择模式。
3. 用 [`lab-command-cheatsheet.md`](Lab命令速查.md) 运行示例。
4. 发布前使用 [`production-checklist.md`](生产清单.md)。
