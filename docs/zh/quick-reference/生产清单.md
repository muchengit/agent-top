# 生产清单

这份清单用于发布前、事故中和 postmortem 后。

## 发布前

- [ ] Auth 和 permissions 已定义。
- [ ] Tool allowlist 和风险分类存在。
- [ ] Destructive actions 需要确认。
- [ ] Safety evals 通过。
- [ ] Golden prompts 通过。
- [ ] Trace fields 存在。
- [ ] Rollback plan 已记录。
- [ ] Cost 和 latency budgets 已设置。
- [ ] Incident owner 已命名。
- [ ] PII handling 和 data retention 已记录。
- [ ] Rate limits 和 retry budgets 已定义。
- [ ] Model/provider fallback 已测试。
- [ ] Regression gate 阻断 safety 和 eval failures。
- [ ] Human escalation path 已记录。

## 事故中

- [ ] Disable risky action path。
- [ ] 必要时 freeze writes。
- [ ] Inspect traces。
- [ ] Identify root cause。
- [ ] Add regression eval。
- [ ] Document postmortem。
- [ ] 通知 stakeholder 并说明 blast radius。
- [ ] 从 traces 和 logs 保留 before/after evidence。
- [ ] 确认 rollback 或 mitigation 有效。

## 事故后

- [ ] Fix owner 和 due date assigned。
- [ ] Rollback tested。
- [ ] Evals updated。
- [ ] 文档 updated。
- [ ] Follow-up monitored。
- [ ] Preventive guardrail added。
- [ ] Action items 已链接到 postmortem。
