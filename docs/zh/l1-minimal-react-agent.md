# L1 最小 ReAct Agent

## 目标

不使用框架，理解并实现一个小型 ReAct 风格循环。

## 前置

- 已完成 L0
- 熟悉 Python 函数和简单控制流

## 核心循环

1. 观察当前状态。
2. 思考下一步动作。
3. 需要时调用工具。
4. 观察工具输出。
5. 在答案就绪或达到停止条件时结束。
