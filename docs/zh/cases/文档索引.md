# 案例研究索引

案例研究把 Agent-Top 的概念、Lab、生产决策连接到接近真实系统的场景。

## 案例

- [`customer-support-multi-agent.md`](多Agent客服案例.md)：多 Agent 客服系统。
- [`enterprise-multi-tool-agent.md`](企业多工具Agent案例.md)：企业多工具 Agent。
- [`multi-agent-collaboration.md`](多Agent协作案例.md)：多 Agent 协作。
- [`pattern-contribution.md`](模式贡献案例.md)：可复用模式贡献。
- [`personal-knowledge-rag.md`](个人知识库RAG案例.md)：个人知识库 RAG。
- [`production-regression-gate.md`](生产回归门禁案例.md)：生产发布门禁。

## 案例规范

每个案例应包含：

- 场景。
- 架构。
- 关键决策。
- 失败模式。
- 评估或生产证据。
- 后续学习。
