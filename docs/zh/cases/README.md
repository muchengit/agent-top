# 案例研究索引

案例研究把概念、Lab、生产决策连接起来，帮助学习者在接近真实系统的场景中理解 Agent 设计。

## 案例

- [`customer-support-multi-agent.md`](customer-support-multi-agent.md)：多 Agent 客服系统，覆盖检索、工具、验证和升级。
- [`personal-knowledge-rag.md`](personal-knowledge-rag.md)：个人知识库 RAG，覆盖检索、记忆和 refusal。
- [`production-regression-gate.md`](production-regression-gate.md)：生产发布门禁，覆盖安全、trace、rollback 和成本。

## 案例规范

每个案例应包含：

- 场景。
- 架构。
- 关键决策。
- 失败模式。
- 评估或生产证据。
- 后续学习。
