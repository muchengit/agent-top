# L5 Custom Patterns

## Goal

Abstract a reusable Agent pattern with stable inputs, outputs, and failure modes.

## Prerequisites

- L0 through L4 completed
- Exposure to at least one production-style Agent system

## What to Prove

- The pattern is reusable beyond one example.
- Safety checks happen before execution.
- Verification is part of the loop.
- The pattern can be maintained by other contributors.
