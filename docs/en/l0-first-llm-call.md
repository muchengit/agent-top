# L0 First LLM Call

## Goal

Run the first LLM request/response cycle and explain the basic concepts.

## Prerequisites

- Python 3.10+
- Basic command line usage

## What You Should Learn

- A prompt is the user instruction.
- A system prompt defines the assistant role.
- A response is generated text.
- Tokens are not exactly words.
- Context window is the model's input budget.
