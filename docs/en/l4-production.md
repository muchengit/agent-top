# L4 Production Agent Systems

## Goal

Turn an Agent prototype into a production-ready system.

## Prerequisites

- L0 through L3 completed
- Working evals, observability, and basic safety guardrails

## Production Checklist

- Auth and permissions.
- Rate limits and cost limits.
- Evaluation set and regression suite.
- Observability traces.
- Rollback plan.
- Postmortem template.
