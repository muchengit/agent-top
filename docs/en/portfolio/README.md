# Portfolio Tracks

Portfolio projects should prove that you can build, test, and explain Agent systems.

## Tracks

- [`projects.md`](projects.md): full portfolio project tracks.

## Four Project Gradients

1. **Personal Knowledge Base Agent** — proves RAG and memory.
2. **Enterprise Multi-Tool Agent** — proves tool orchestration and MCP-style boundaries.
3. **Multi-Agent Collaboration System** — proves orchestration, consistency, and error isolation.
4. **Custom Framework or Pattern** — proves abstraction, engineering depth, and contribution readiness.

## Evidence Expected

For each project, include:

- Architecture diagram or Mermaid flow.
- Runnable command or test output.
- Eval or self-check results.
- Failure modes and rollback notes.
- Trade-off explanation.
- Related Lab or docs link.

## Reviewer Questions

- Can this project run locally?
- Does it separate evidence from generated claims?
- Are tool permissions explicit?
- Is there a failure path, not just a happy path?
- Could another contributor maintain it?
