# L1 Minimal ReAct Agent

## Goal

Understand and implement a tiny ReAct-style loop without using a framework.

## Prerequisites

- L0 completed
- Comfort with Python functions and simple control loops

## Core Loop

1. Observe current state.
2. Think about the next action.
3. Call a tool when needed.
4. Observe tool output.
5. Stop when the answer is ready or a stop condition is reached.
