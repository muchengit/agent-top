# Practice And Lab Handbook

Use this handbook to turn learning materials into portfolio evidence.

## Two Practice Tracks

- **Examples**: local, fictional, no-API-key exercises in [`../../../examples/README.md`](../../../examples/README.md).
- **Labs**: deterministic runnable tests in [`../../../labs/README.md`](../../../labs/README.md).

## How To Use Them

1. Pick one capability level from [`learning-paths.md`](learning-paths.md).
2. Run the matching Lab if you want executable proof.
3. Complete one matching Example if you want design evidence.
4. Write a short artifact: decision log, design note, review result, or postmortem.
5. Explain the trade-off in three sentences.

## Evidence Format

For every practice item, keep:

- Task.
- Decision or output.
- Evidence link.
- Trade-off.
- Follow-up.

## Self-Assessment

You are ready to move on when you can:

- State the failure mode.
- Name the evidence source.
- Explain why the tool action was allowed or blocked.
- Describe how to test the decision again.
- Say what would change if a source was stale.
