# Interview Framework

Interview questions are organized by capability level and depth.

## Matrix

| Level | Concept | Implementation | Debugging | Design |
| --- | --- | --- | --- | --- |
| L1 | Explain perception, planning, tools, memory | Minimal ReAct loop | Failed tool loop | Single agent shape |
| L2 | Compare frameworks by pattern fit | Guardrailed single Agent | MCP failure handling | Tool routing |
| L3 | Explain RAG-memory-multi-agent data flow | Pipeline integration | Retrieval misses | Customer support system |
| L4 | Production eval tradeoffs | Regression suite | Incident triage | Cost / latency / safety |
| L5 | Architecture tradeoffs | Original framework pattern | Cross-team failure mode | Ecosystem strategy |

## What Interviewers Should Hear

- Trade-offs, not slogans.
- Production counterexamples.
- Data-driven evaluation choices.
- Explicit assumptions.
- Clear incident response and prevention.

## STAR Template

- Situation: context and constraint.
- Task: what you owned.
- Action: decisions, architecture, tests, safeguards.
- Result: metric, learning, and follow-up.
