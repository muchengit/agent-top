# Interview Questions Index

Agent-Top question sets are organized by capability level and question depth.

## Question Sets

- [`l1-components.md`](l1-components.md): core Agent components and minimal loops.
- [`l2-framework-mcp.md`](l2-framework-mcp.md): framework fit, tool boundaries, and MCP-style failures.
- [`l3-system-design.md`](l3-system-design.md): RAG, memory, MCP, and multi-agent systems.
- [`l4-production.md`](l4-production.md): incident response, evals, rollback, and production trade-offs.
- [`l5-patterns.md`](l5-patterns.md): original patterns, framework strategy, and ecosystem impact.

## Authoring Rules

Each question should include:

- A clear question.
- Expected answer points.
- Interviewer listening notes.
- At least one follow-up.
- A production or trade-off angle where relevant.

## Difficulty Labels

- `basic`: checks vocabulary and stable concepts.
- `applied`: checks implementation or debugging.
- `design`: checks architecture under constraints.
- `expert`: checks original contribution or cross-team judgment.

## Quality Bar

A good Agent-Top interview question should make a strong candidate explain:

- Why the design works.
- What can fail.
- How it is measured.
- How it is rolled back.
- What trade-off was accepted.
