# Quarterly Maintenance Checklist

## Review Scope

- Docs freshness.
- Broken links.
- Version anchors.
- Translation sync lag.
- CI status.
- Deprecated content archive queue.

## Actions

1. Run repository checks.
2. Scan Markdown links.
3. Flag `sync-required` for stale translations.
4. Add `deprecated` to outdated examples.
5. Publish Contributor of the Month summary.
6. Update roadmap status.

## Exit Criteria

- Dead link rate below 1%.
- No known broken CI job.
- Deprecated pages point to replacements.
