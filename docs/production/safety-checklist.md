# Agent Safety Checklist

## Required

- Auth and permissions.
- Tool allowlist.
- Input validation.
- Output validation.
- Rate limit.
- Cost limit.
- Observability.

## Guardrails

- Block irreversible actions without confirmation.
- Reject malformed tool arguments.
- Redact sensitive data where possible.
- Log denied actions for auditability.
