# Agent Evaluation Checklist

## Required

- Golden prompts.
- Tool usage correctness.
- Retrieval correctness.
- Safety rejection cases.
- Latency and cost baseline.

## Regression

- Re-run after prompt changes.
- Re-run after tool schema changes.
- Re-run after retrieval source changes.

## Reporting

- Correctness.
- Hallucination or unsupported claims.
- Cost per task.
- Latency percentile.
