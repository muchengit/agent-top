# Contribution Paths

Agent-Top accepts four main contribution types.

## Writing

- Write tutorials or Labs.
- Prefer Markdown + executable code.
- Keep framework code in Labs.

## Translation

- Claim `translation-needed` issues.
- Keep `i18n-key` aligned between EN and ZH.
- Update `last-synced` when translation changes.

## Review

- Reviewer handles ordinary Labs and docs.
- Maintainer handles architecture, safety, and deployment topics.
- Same author should not self-review the same module in the same month.

## Maintenance

- Keep dead links below 1%.
- Keep version anchors fresh.
- Archive deprecated content after one quarter.
