# Community Lab Host Script

## Opening: 5 minutes

State the goal:

> Today we are going to understand one Agent pattern and finish with one runnable or reviewable artifact.

Set the ground rules:

- One topic only.
- Ask what you do not understand.
- Keep examples local when possible.
- Prefer trade-off explanations over slogans.

## Concept Segment: 10 to 15 minutes

Ask the group:

1. What problem does this pattern solve?
2. What input does the system receive?
3. What output does it produce?
4. What can fail?
5. Where is safety checked?

## Hands-On Segment: 20 to 35 minutes

Pick one of these paths:

- Run a Lab and explain the output.
- Walk through a short code example.
- Translate or improve a docs section.
- Add one interview question or self-check.

Stop when everyone can explain:

- What the code or tutorial does.
- Where it stops.
- What should be tested.

## Trade-off Segment: 10 to 15 minutes

Ask:

- Why not use a framework here?
- Why not add more agents?
- What happens if the model changes?
- What evidence is missing?
- What rollback path exists?

## Close: 5 minutes

Confirm:

- One artifact exists.
- One follow-up task is assigned.
- The next session topic is proposed.
