Quality Gates

Run the four quality-gate commands locally before opening a pull request:

  • python scripts/check_repository.py — repository structure, links, bilingual metadata, labs, examples, and docs-site links
  • python -m unittest discover -s labs -p "test_*.py" — all lab tests
  • python3 -m ruff check . — lint the whole repository
  • python3 -m compileall -q labs scripts — byte-compile every Python file under labs and scripts

Bilingual Reconciliation

docs/en is the primary source; docs/zh stays in sync through explicit frontmatter metadata. See Translation Workflow and 翻译工作流.

  • i18n-key parity — every page under docs/en and docs/zh carries a byte-identical i18n-key; the repository check fails when an EN key has no ZH pair.
  • last-synced principle — last-synced records when the ZH page last matched the accepted EN source; it is updated by the translator or language reviewer, never by the source author alone.

CI Workflows

GitHub Actions config: .github/workflows/ci.yml.

docs-quality

  • Runs python scripts/check_repository.py on Python 3.11
  • Runs python -m unittest discover -s labs -p "test_*.py" and python3 -m ruff check .
  • Runs python3 -m compileall -q labs scripts and python scripts/smoke_multilingual_labs.py

link-and-artifact-integrity

  • Re-runs python scripts/check_repository.py
  • Verifies every examples/ directory has a README and non-empty JSONL
  • Checks docs/en vs docs/zh Markdown count parity (difference ≤ 5)
  • Confirms README.md and README.zh-CN.md mention labs/l0..labs/l5
