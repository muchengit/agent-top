# 贡献检查清单

开 PR 之前使用。

## 范围

- [ ] 变更小而可审查。
- [ ] PR 摘要中陈述目标。
- [ ] 非目标清晰。
- [ ] 检查过既有 docs 或 Labs 是否有重叠。

## 文档

- [ ] 改动的 Markdown `validated_date` 是最新的。
- [ ] 相对链接在当前文件位置可用。
- [ ] Markdown 可读且与 `STYLE.md` 一致。
- [ ] 框架特定内容与稳定概念分离。
- [ ] 示例不重复 Lab 源码。

## 双语文档

- [ ] 英文和中文文件使用相同 `i18n-key`。
- [ ] 翻译或镜像内容更新了 `last-synced`。
- [ ] `docs/zh` 下已有中文文件名的地方沿用中文名。
- [ ] 术语保持一致。

## Labs 与 Examples

- [ ] 新 Lab 有代码和确定性测试。
- [ ] 新 Lab 包含 Goal、Prerequisites、Run、Common Pitfalls 和 Self-Check。
- [ ] Example JSONL 文件有效。
- [ ] Example 练习不需要 API key 或外部服务。
- [ ] Lab README 列出预期输出或验证方式。

## 安全与生产

- [ ] 工具动作分类为读、写或破坏性。
- [ ] 破坏性动作需要确认或审批。
- [ ] 隐私敏感数据为虚构或合成数据。
- [ ] 安全相关主题包含维护者审查。
- [ ] 相关时描述回滚或失败处理。

## L5 专家证据

- [ ] 如果本 PR 声称 L5 就绪，需包含或链接 L5 专家证据包。
- [ ] L5 声明区分模式质量、治理质量和外部影响力。
- [ ] L5 工作包含失败模式、非目标、被拒替代方案和残余风险说明。
- [ ] 涉及安全、发布、权限或治理的 L5 工作需标注维护者审查。

## 验证

- [ ] `python scripts/check_repository.py`
- [ ] `python -m unittest discover -s labs -p "test_*.py"`
- [ ] `python -m compileall -q labs scripts`
- [ ] `python -m ruff check .`
