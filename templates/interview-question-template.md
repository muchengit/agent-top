# Interview Question

## Question

State the prompt clearly.

## Context

- User or production setting.
- Key constraints.
- Missing assumptions the candidate should state.

## Expected Answer Points

- Key point.
- Trade-off.
- Production consideration.

## What the Interviewer Should Listen For

- Evidence of data thinking.
- Honest failure modes.
- Clear boundaries of the solution.
- Cost, latency, or safety awareness when relevant.

## Follow-ups

1. Follow-up question.
2. Deeper production question.
3. Debugging or rollback question.
