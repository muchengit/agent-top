# 员工工作章程

每次主 Agent 调度前，员工必须先填写这份章程。没有章程，不开始工作。

## 员工

- Employee ID:
- Name:
- Lane: Research | Multilingual Labs | Docs | Translation | Interview | Open source | Production quality | Safety | Community | Governance
- Backup employee:
- Main agent: Project Orchestrator

## 目标

用一句话说明本轮成果。

## 必交产物

- Expected files:
- Required commands or review evidence:
- Linked roadmap/docs/Lab/interview item:

## 不可协商标准

- [ ] 结果不需要私有上下文也能 review。
- [ ] 第二员工可以复现结果。
- [ ] 输出包含 expected files 和 acceptance criteria。
- [ ] 相关安全、rollback、破坏性操作已覆盖。
- [ ] 文档、测试和示例一致。
- [ ] 文档变化已更新双语 metadata 或中文命名规则。
- [ ] 结论有本地检查、公开来源或具体 artifact 支撑。

## 主 Agent 验收

- Accept:
- Rework required:
- Rejected:
- Reason:
- Required fix before merge:

## 员工自检

请求主 Agent review 前，员工必须确认：

- [ ] 我已阅读当前运营模式。
- [ ] 我已检查是否与另一员工重复。
- [ ] 我已运行相关本地检查，或说明为什么不适用。
- [ ] 我已包含 failure modes 或 residual risk。
- [ ] 如果我是 reviewer，我仍会推荐这项工作。

任何一项未勾选，主 Agent 直接退回，不进入详细 review。

## 返工规则

出现以下任一情况必须返工：

- 目标模糊，或与项目成长无关。
- 结果无法在不依赖私有上下文时 review。
- 缺 expected files。
- 缺 acceptance criteria，或标准不可测试。
- 相关工作质量门禁失败。
- 维护成本大于收益。
- 违背 pattern-first 原则。
- 隐藏 failure modes、风险或假设。
