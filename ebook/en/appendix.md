# Appendix: Templates and Governance

This appendix collects the repository artifacts that help readers convert practice into reviewable evidence.

## Templates

Start with the template closest to the task:

- `templates/article-template.md`
- `templates/lab-template.md`
- `templates/agent-design-template.md`
- `templates/eval-report-template.md`
- `templates/postmortem-template.md`
- `templates/agent-skill-card-template.md`

## Governance

Use governance documents when the work affects more than one contributor or production system:

- `GOVERNANCE.md`
- `CONTRIBUTING.md`
- `SECURITY.md`
- `CODE_OF_CONDUCT.md`
- `ROADMAP_STATUS.md`

## Quality Gates

Before releasing an Agent-Top-based artifact, check:

- Source links resolve.
- Lab commands run locally.
- Version anchors are present where required.
- Evaluation evidence is reproducible.
- Safety and cost tradeoffs are documented.
